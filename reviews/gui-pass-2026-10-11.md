# GUI test pass, 2026-10-11

Run by Claude with computer use on a dev build. The Codex app's pass couldn't run: its computer-use helper crashed reading the window. That was partly triggered by controls without accessibility labels, now fixed (see `codex-review-2026-10-11.md` for the code review). Fixtures were Codex's, in `~/Desktop/lacquer-gui-test/fixtures`.

## Checked and working

- **Adding files:** Open With, both cold and warm launch; a dropped folder expands to its films; duplicate files are skipped.
- **Per-job defaults:** six mono tracks become 5.1, 29.97p goes to 1080i29.97, 50p to 1080i25, silent sources get a note, HDR sources get a note.
- **Per-job overrides:** forcing 29.97p to 1080p23.976 shows the 20% frame-drop warning, and resetting clears it.
- **Too long:** a 60-hour file shows a red meter, a badge and a reason; the queue fails it at once, without encoding.
- **Sidebar:** audio bitrate changes update every waiting row immediately; Save to persists across relaunches.
- **Unwritable Save to folder:** caught before any encoding.
- **Full run:** four discs written. ffprobe confirms H.264 at the promised format, `field_order=tt` for the 1080i discs, 6-channel AC-3 for mono6, stereo AC-3 for the others, 0644 permissions, and the quote in a filename replaced by an apostrophe.
- **Subtitles:** a Windows-1252 .srt tagged Spanish gives a PGS track tagged `spa`, with accents rendered correctly. This is the first visual check of PGS output.
- **Stop (⌘.):** ffmpeg exits, the partial disc is deleted, the log says STOPPED, and the job can be retried.
- **Quit while encoding:** a confirmation appears; Keep Encoding continues; Quit stops the job, waits for cleanup, then exits with no ffmpeg left behind.
- **About panel, Activity panel, Queue menu.**

## Defects found and fixed in this pass

1. Damaged files produced raw ffprobe output under "Something went wrong". Now there's a plain-language reason, and each alert has its own title.
2. The too-long advice suggested 448 kbps audio for a silent disc and BD-50 when already on BD-50. Now it only suggests changes that would make the film fit.
3. The footer total counted files that can't fit.
4. An unwritable Save to folder failed every job in turn. Start now refuses once, with an alert.
5. Retrying meant clicking every failed job. Added Retry All, in the footer and the Queue menu.
6. A failed job showed its reason twice.
7. "About 0 sec left" appeared at the end of a job.
8. Stop had no shortcut. Added ⌘., plus a Queue menu with Start (⌘↩), Stop, Retry All, Clear Done, and File › Add Files (⌘O).
9. **Quitting mid-encode killed ffmpeg before the job could clean up.** Quitting during authoring could have left a partial disc, and the log said FAILED. Quit now stops the job and waits for cleanup, up to 10 s.
10. **The quit dialog's default button was Quit, so Return discarded the encode.** Keep Encoding is now the default, and Quit is marked destructive.
11. **Subtitles sat 21 px from the bottom edge,** inside the strip TVs with overscan crop. They now sit 7% up.
12. A gap in the subtitle row, and a duplicated license line in About.
